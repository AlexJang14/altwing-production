## Method

1. Read the exact five AltWing stems, all response categories, the main story prompt and the three optional reflection prompts in `src/features/analytics/assessmentModel.ts`.
2. Inspect actual publicly available source items, sample items or question examples where available, and the relevant conceptual material where a reference is a standard, policy synthesis or methods guide. Compare wording, unusual phrase combinations, operational meaning, question structure and response format. The table below names the closest comparators rather than reproducing source questionnaires.
3. Run quoted full-stem web searches as a secondary check. Results broadened to unrelated text rather than establishing an exact copied questionnaire. Search-engine treatment of quotation marks/index coverage is uncertain; this is not evidence that all Internet wording has been exhaustively searched.
4. Record versions and access limits. Author-hosted public PDFs were read through ordinary HTTP/HTTPS requests and local text extraction; no credentials, paywall bypass, purchase or provider contact was used. Public availability is not a reuse license. Source PDFs/item tables are not included in the public review package; their identifiers and retrieval hashes are.

There is no numerical plagiarism score or threshold that purports to settle originality. Shared construct names and ordinary response labels were distinguished from an identified distinctive item reproduction. All five items and the story were checked against the accessible material from all seven references; the closest comparisons are highlighted below.
