## How to read the register

**VERIFIED LICENSE** means identified material was matched to a source/license and the applicable notice was retained. It does not certify every other right, endorsement or unrelated content. **UNVERIFIED** means evidence is missing; it is not an accusation of infringement. **DOCUMENTED ORIGIN** records custody or generation without treating that as complete rights clearance. **RETIRED** means not included in the proposed active source/build, not that old rights were established.

The companion `inherited-file-register.csv` identifies every file present in the production baseline by path and Git blob, its current SHA-256 or deletion, category, applicable case and rights status. A modified file can still contain unresolved inherited material. The software inventory remains package-by-package in `public/dependency-inventory.json`; it must not be confused with the inherited first-party source register.

## Evidence submission format

Keep permission documents and account exports in a private location; the public repository should hold a redacted reference, scope, evidence identifier/date, document hash and review conclusion. Do not publish administrator emails, signatures, student identities, passwords, session tokens or full private conversations.

For R01 or a specifically identified outside contribution requiring permission, supply: **(1)** case ID and exact paths/blobs or content families covered; **(2)** creator/rightsholder and how they obtained rights; **(3)** source/license or their actual dated permission statement; **(4)** allowed uses (public website, modification, branding if relevant, source distribution); **(5)** attribution, restrictions, exclusions and third-party inputs; **(6)** a private evidence file and redacted summary. A license URL alone needs a match to the actual asset/version. Permission from one contributor must not be represented as permission from all contributors.

This is an evidence checklist, not a pre-written permission asserting facts on someone else's behalf. Provide genuine existing records or obtain genuine permission; do not sign another person's name or invent provenance. We will update individual statuses only when supporting evidence is inspected.
